# DYNOVA NETWORK

Video-rating earning platform with 3-level referrals, monthly salary ranks,
joining bonuses, deposit/withdraw, and a full admin panel.

## Deploy

- **Hostinger / cPanel shared hosting** → see **[HOSTINGER_DEPLOY.md](HOSTINGER_DEPLOY.md)** (start there).
- **Cron / scheduler / day-2 ops**       → see **[DEPLOY.md](DEPLOY.md)**.
- **localhost / XAMPP**                  → see **[INSTALL.md](INSTALL.md)** option B.

## Default credentials (change on first login)

- Admin: `admin@dynova.com` / `password`

## Tech

- PHP 8.0+ · MySQL / MariaDB · vanilla front-end (no build step) · single-file cron scheduler.
